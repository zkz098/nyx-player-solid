The core layer is framework-agnostic (no `solid-js` / DOM dependency) and available from the top-level `nyx-player-solid` entry.

## PlayerCore

The playback state machine (unidirectional: action → setState → notify; audio side effects are internal — no event bus).

```ts
const core = new PlayerCore({ adapter?, provider?, initialMode?, initialVolume? });
await core.init(sources);
core.play(); core.pause(); core.toggle();
core.next(); core.prev();
core.seek(30); core.setMode("random"); core.cycleMode();
core.setVolume(0.5); core.toggleMute();
core.selectPlaylist(1); core.playSong(1, 2);
core.back(); core.forward(); core.clearHistory();
const state = core.getState();
const unsubscribe = core.subscribe((next) => ...);
```

### PlayerState fields

`playing` / `currentTime` / `duration` / `mode`(`order|random|loop`) / `playlists` / `playlistNames` / `playlistIndex` / `perSongIndex` / `perLastIndex` / `volume` / `muted` / `loading` / `error`.

### Current track

```ts
import { currentSongOf } from "nyx-player-solid";
const song = currentSongOf(core.getState()); // Song | null
```

### Play history

`getHistory(): HistoryEntry[]`, `HistoryEntry = { playlistIndex, songIndex }`. `back`/`forward` are browser-style navigation; explicit navigation (next/prev/playSong) drops the forward branch.

## AudioAdapter

`AudioAdapter` is the only layer allowed to touch the real audio engine (default `HTMLAudioAdapter`; injectable for tests/custom).

```ts
interface AudioAdapter {
  setSrc(url: string): void;
  play(): Promise<void>;            // may be rejected by autoplay policy
  pause(): void;
  seek(time: number): void;
  setVolume(v: number): void;
  setMuted(m: boolean): void;
  getCurrentTime(): number;
  getDuration(): number;
  on(event: AudioAdapterEvent, handler: () => void): () => void;
  getContextAnalysis?(): AnalyserNode | null; // R4: visualization
  dispose(): void;
}
```

Events: `timeupdate` / `ended` / `error` / `loadedmetadata` / `play` / `pause`.

## Lyrics parsing

| Function | Description |
| --- | --- |
| `parseLyric(text)` | Standard LRC → `LyricLine[]` (`{ text, start, end }`, end auto-aligned) |
| `parseLyricLine(line)` | Single-line timestamp → seconds (throws on invalid) |
| `findActiveLyricIndex(lines, time)` | Locate the active line (linear, falls back to the last line) |
| `parseWordLyric(text)` | LLRC word timestamps → `WordLyricLine[]` (degrades to whole-line for plain LRC, **LRC-compatible**) |
| `activeWordIndex(words, time)` | Karaoke: last active word index |
| `fetchLyricText(urlOrText)` | Fetch by URL / return inline text directly (bounded cache, 8s timeout) |

## Other utilities

- `runWithPool(items, limit, fn)` / `ConcurrencyPool`: concurrency-limited execution (playlist fetching)
- `parsePlaylistUrl(url)` / `hasPlaylistURL(url)`: playlist URL resolution (netease / tencent)
- `createHTMLAudioAdapter(element?)`: browser audio adapter (accepts an existing `<audio>` element)
- `createNoopAdapter()`: SSR-safe no-op
