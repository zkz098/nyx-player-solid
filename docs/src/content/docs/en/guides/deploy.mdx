The docs site is fully static (`output: "static"`) with no SSR adapter requirement — any static host works. The following uses **Cloudflare Pages** (directly applicable to Netlify / Vercel / GitHub Pages).

## Git integration (recommended)

1. Cloudflare dashboard → **Workers & Pages → Create → Pages → Connect to Git**
2. Pick the repository, configure the build:
   - **Framework preset**: None (or Astro if detected)
   - **Build command**: `pnpm docs:build`
   - **Build output directory**: `docs/dist`
   - **Root directory**: *(repo root — `pnpm docs:build` builds player artifacts first, then the docs)*

3. After the first deploy, bind a domain under **Custom domains**.

## Local build and preview

```bash
pnpm install
pnpm build        # player dist artifacts (demo page depends on them)
pnpm docs:build   # docs → docs/dist
pnpm docs:preview # preview the built output locally
```

## Environment variables

| Variable | Purpose |
| --- | --- |
| `CLOUDFLARE_PAGES_URL` | Deploy domain override (Cloudflare injects the `*.pages.dev` URL automatically) |

`astro.config.mjs` reads it as `site` so the sitemap / canonical URLs point at the right domain.

## CLI deployment (optional)

```bash
# requires wrangler CLI and a Pages project
pnpm dlx wrangler pages deploy docs/dist --project-name nyx-player-solid
```

## Hosting notes

- `public/demo/` player artifacts (copies of `dist/*.js/css`) are generated by the build script — build outputs, do not commit by hand
- With aggressive CDN caching, consider short/no cache for `demo/nyx-player.*.js` (filenames carry no hash; revisions need a refresh)
