## Running the docs locally

```bash
# 1. build the player artifacts first (demo page needs dist)
pnpm build
# 2. start the docs
pnpm docs:dev        # http://localhost:4321
```

## Customizing demo data

The demo sources live in `docs/static/demo/`; the build script `scripts/build-demo.mjs`:

1. Verifies `dist/` artifacts exist (hints `pnpm build` otherwise)
2. Copies `dist/nyx-player.js` / `dist/nyx-player.css` into the docs static dir
3. Generates `index.html` (references the copied artifacts + your config)

Edit `docs/static/demo/sources.js` (the track list) and re-run `pnpm docs:build`.
